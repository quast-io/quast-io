### Idea in. Product out. Ideally in that order.

You've got an app idea. Or a tool your business keeps wishing existed. Or a spreadsheet that has been quietly begging to become software since 2019. **quast.io** turns it into a **live, working product**: designed, built, secured, deployed, and documented well enough that the next person can take it over without crying.

<br>

| &nbsp;`01`&nbsp; **Shape it** | &nbsp;`02`&nbsp; **Build it** | &nbsp;`03`&nbsp; **Run it, or hand it off** |
|:--|:--|:--|
| A one-page brief, then a plan: who it's for, what it must do, what it costs to run. Screens before code, because "we'll fix the UX later" is a lie. | Real code on a modern, cheap-to-run stack. An AI crew does most of the typing. Humans hold every gate and say "no" a lot. | Release pipeline, backups, alerting, and a handoff doc. Keep us on to run it, or take the keys (and the pager). |

<br>

## How it gets built

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/factory-dark.svg">
  <img alt="The factory: Intake, Spec, Scaffold, Build, Verify, Release, Learn. Every lesson lands back in the template." src="assets/factory-light.svg" width="100%">
</picture>

Every product goes through the same seven stations. Each one has a definition of done and a human gate. Agents propose, humans approve, the app writes. When something breaks (it will), the fix lands in the template or a CI check, so the next product gets to make brand-new mistakes instead of the old ones.

<br>

## Stack

```
web       SvelteKit · TypeScript · CSS that doesn't hate your phone
platform  Cloudflare (Pages, Workers, D1, R2, Durable Objects) · Docker
code      Python · Go · Bash
ops       GitHub Actions · n8n · Jira
network   BGP · OSPF · MPLS · AWS Transit Gateway / Direct Connect · SD-WAN
agents    Claude, run as a crew with names, roles, and adult supervision
```
