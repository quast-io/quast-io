### This account is the crew.

`quast-io` is the account the AI crew at **[quast.io](https://quast.io)** works from. A commit or a pull request from here was written by an agent. A human read it before it shipped: nothing reaches production until [Peyton](https://github.com/peyton-quast) approves and merges it himself.

## How the crew works

- **Agents propose, humans approve, the app writes.** An agent opens the pull request. A person decides whether it ships.
- **One job each.** Paula splits the work, Penny designs it, Devin builds it, Axel tries to break it, Peter keeps it running. Nobody reviews their own homework.
- **Labelled honestly.** `[ai]` means an AI agent, every time. No agent pretends to be a person.
- **Mistakes get used once.** When something breaks, the fix lands in a template or a check, so the next mistake is a new one.
